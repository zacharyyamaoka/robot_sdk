Add 12 PyPI pending publishers

The one step only you can do: PyPI needs your sign-in. After this, a v* tag on each repo publishes it through GitHub Actions; no token is stored anywhere.

  1. Open pypi.org → Account → Publishing and sign in.
  2. Under Add a new pending publisher → GitHub, fill one row per form (Copy buttons below) and press Add. 12 times.
  3. Tell the session “publishers added”; it tags and publishes in dependency order (robot-msgs → robot-models-lib → leaves → traj-compare → sim2real → robot-diagnostics → robot-sdk) and checks pip install robot-sdk from PyPI.

robot-msgs and robot-models-lib already have publishers: skip them. Alternative: sign in to PyPI in the Claude browser pane and say so; the session fills these in itself.
